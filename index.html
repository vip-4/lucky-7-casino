賠付線（Payline）
本遊戲固定三條水平線：上排、中排、下排。從左至右讀取三個符號。
加權隨機（Weighted RNG）
每個符號依權重被抽取，權重越高出現越頻繁；此機制只控制視覺結果，不代表任何真實博弈公平性。
狀態機（FSM）
遊戲在 Idle → Spinning → Evaluating → Idle 之間轉換，避免重複下注與競態條件。

SEO、GEO 與工程實作要點

本節說明站點如何同時滿足搜尋引擎爬索引與生成式引擎摘要引用，並兼顧行動端效能與無障礙。

SEO：可被發現

  • 完整 title、description、keywords、robots 與 canonical。
  • Open Graph 與 Twitter Card，包含 1200×630 圖片與維度宣告。
  • JSON-LD：WebSite、Organization、SoftwareApplication、BreadcrumbList、FAQPage。
  • robots.txt 與 sitemap.xml 便於爬蟲發現。

GEO：可被引用

  • 答案前置段落，每段可獨立摘要，不依賴上下文。
  • 語意化 h1–h3、dl、table 與 FAQ 區塊。
  • 頁面文字靜態存在於 HTML，不需執行 JavaScript 即可讀取。
  • llms.txt 提供給 AI 爬蟲的精簡結構化摘要。

效能：60 FPS 目標

  • 零第三方套件、零外部字型，總資源體積維持在數十 KB 等級。
  • 單一 Canvas + 物件池粒子，避免頻繁配置造成的 GC 卡頓。
  • 裝置像素比上限設為 2，降低高 DPI 手機填充率負擔。
  • requestAnimationFrame 統一渲染，分頁隱藏時暫停。

無障礙與相容性

  • 跳至內容連結、ARIA live 狀態播報、可見焦點樣式。
  • 支援空白鍵旋轉與 prefers-reduced-motion 動效降級。
  • WebGL 上下文遺失以防禦性設計規避：本作使用 Canvas 2D，無 WebGL 依賴。
  • 音效需使用者手勢解鎖，符合 iOS Safari 自動播放政策。

常見問題

什麼是幸運 7 老虎機？

幸運 7 老虎機是一款純前端的 HTML5 老虎機示範遊戲，採用 3×3 滾輪與 3 條賠付線。玩家使用虛擬籌碼下注並旋轉滾輪，當同一條賠付線出現三個相同符號即可獲得虛擬籌碼獎勵。它不涉及真實金錢，僅供技術展示與娛樂。

這款遊戲需要註冊或下載嗎？

不需要。遊戲為靜態單頁，所有的 HTML、CSS 與 JavaScript 都可以直接由瀏覽器執行，無需後端、會員系統或任何外掛程式。首次點擊或按鍵會解鎖 Web Audio 音效。

如何計算中獎？

每次旋轉後，系統會檢查上、中、下三條水平賠付線。若任一條線上的三個符號相同，即依該符號的倍率乘以本次下注額派發虛擬籌碼；多條線同時中獎時會累加。機率與賠率表可在頁面「遊戲規則」一節查閱。

前端的隨機數可以用於真實博弈嗎？

不可以。本示範使用瀏覽器 crypto.getRandomValues 產生隨機數，僅能作為表現層演示。正式博弈平台必須由伺服器端 RNG 決定結果、伺服器結算並記錄可稽核日誌，前端不得決定中獎與派彩，亦不可存放可被竄改的關鍵數值。

什麼是 GEO 生成式引擎優化？

GEO（Generative Engine Optimization）是讓內容更容易被 AI 摘要與引用的優化方式。實作重點包括：答案前置的段落結構、語意化標題階層、FAQ 與定義列表、JSON-LD 結構化資料、明確的來源與更新日期，以及不依賴 JavaScript 就能被爬取的文字內容。

這個站點如何兼顧效能與無障礙？

站點不使用任何第三方框架或字型，單一 Canvas 搭配物件池粒子效果，並將裝置像素比上限設為 2 以控制填充率。無障礙方面提供跳至內容連結、ARIA 狀態播報、鍵盤旋轉操作、可見焦點樣式，以及尊重 prefers-reduced-motion 的動效降級。
